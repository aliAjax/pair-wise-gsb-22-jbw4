# hxwl-08 葡萄酒盲品训练 · 错因诊断本

盲品答错后，分清错在**品种、产区还是香气线索**的诊断与复练系统。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 工作流程

1. **学员作答**：选择学员与酒款，记录答对/答错。
2. **错因自诊**：答错后选择错因（品种 / 产区 / 香气线索）并写下当时依赖的线索。
3. **讲师确认**：核对错因、补充说明，安排下一次复练日期。
4. **分歧裁定**：两人对同款酒选择不同错因时，记录停在「待裁定」；讲师必须写清取舍理由，采纳哪种错因、另一种为何不对，之后才更新复练顺序。
5. **离开名单**：同一学员对同款酒连续答对两回，自动离开复练名单；之后再答错则重新进入。
6. **复练排序**：名单按讲师排定的日期升序，标记今日到期。

## 模块划分

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 酒款、学员、诊断、名单等领域模型 |
| `src/wineData.ts` | 酒款资料与种子数据 |
| `src/diagnosis.ts` | 判定、错因合并/分歧检测、讲师确认与裁定、复练排序（纯函数） |
| `src/storage.ts` | localStorage 持久化，重开页面接着处理 |
| `src/PracticePage.tsx` | 学员作答与错因自诊页 |
| `src/InstructorPage.tsx` | 讲师确认、分歧裁定页 |
| `src/RosterPage.tsx` | 复练名单与已离开名单页 |
| `src/App.tsx` | 标签页、指标看板、状态接线与自动保存 |

数据保存在浏览器 localStorage（键 `hxwl-08.diagnosis-book.v1`），可在页面右上角一键清空重开。

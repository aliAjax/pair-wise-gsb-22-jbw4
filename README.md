# hxwl-08 盲品错因诊断本

产区、品种与感官特征的盲品复习系统：答错先诊断错因，讲师确认后进入复练名单，连续答对两回才能离开名单。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 功能

- 酒款作答：每款酒答错后选择错因（品种误判 / 产区误判 / 香气线索遗漏）并写下线索
- 讲师确认：确认诊断后自动安排下一次复练
- 待裁定：同款酒两人选了不同错因时，记录停在待裁定；讲师写清取舍后才更新复练顺序
- 复练名单：答对累计连对，答错清零并排到队尾，连续答对两回离开名单
- 本地保存：诊断与复练进度存在浏览器 localStorage，重开页面接着处理

## 模块划分

- `src/data/wines.ts` —— 酒款资料：盲品酒单、学员名册、错因选项
- `src/domain/diagnosis.ts` —— 判定与排程：诊断状态迁移、待裁定、复练排序（纯函数）
- `src/storage/persist.ts` —— 保存：localStorage 读写、版本校验与重置
- `src/App.tsx` 与 `src/ui/` —— 页面：作答区、讲师工作台、复练名单、诊断档案
